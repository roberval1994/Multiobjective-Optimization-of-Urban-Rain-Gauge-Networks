# Data access / Acesso aos dados

Some datasets are **too large to version on GitHub** (notably the WorldPop raster,
~457 MB, which exceeds GitHub's 100 MB per-file limit). They are **not** included in this
repository. This guide explains how to obtain each source and where to place it.

Alguns conjuntos de dados são **grandes demais para versionar no GitHub** (em especial o
raster do WorldPop, ~457 MB, acima do limite de 100 MB por arquivo do GitHub). Eles **não**
estão incluídos neste repositório. Este guia explica como obter cada fonte e onde colocá-la.

## Expected layout / Estrutura esperada

```
data/
├── worldpop/
│   └── bra_pop_2025_CN_100m_R2025A_v1.tif   # download manually (see below)
├── risk/                                     # GeoSanja / SJC flood & geological polygons
├── rainfall/                                 # PlugField 2025 rain-gauge records
└── grids/                                    # processed grids (.parquet) generated by the notebooks
```

## Sources / Fontes

| Dataset | Source | How to get it |
|---|---|---|
| **Population** (100 m raster) | [WorldPop](https://www.worldpop.org/) — Brazil, Constrained, 2025, R2025A | Download `bra_pop_2025_CN_100m_R2025A_v1.tif` and place it in `data/worldpop/`. |
| **Hydrological risk** | GeoSanja / Prefeitura de São José dos Campos | Flood and geological-risk polygons. Request/download from the municipal geoportal. |
| **Rainfall** | PlugField (2025) | Rain-gauge records for São José dos Campos. Provided by the data owner. |

## Reproducibility / Reprodutibilidade

The processed grids (`.parquet`) are **generated by the notebooks** from the sources above.
Run the notebooks in `notebooks/` to regenerate them locally — they are intentionally not
committed to keep the repository lightweight.

Os grids processados (`.parquet`) são **gerados pelos notebooks** a partir das fontes acima.
Execute os notebooks em `notebooks/` para regerá-los localmente — eles não são commitados
de propósito, para manter o repositório leve.
